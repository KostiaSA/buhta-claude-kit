# Печатные шаблоны БУХты ([Отчет]) — чтение / правка / печать

> **Ключи «через автоматизацию» / «живой exe»** = работать с запущенным .exe (HTTP-автоматизация `127.0.0.1:8765` через `tools/buhta_client.py`), а не править исходники Delphi в `c:\bm`.

## Что это
Печатные формы БУХты (накладные, счета-фактуры, книги, декларации, ведомости, балансы) хранятся в
таблице `[Отчет]` (ключ `[Ключ]`) и печатаются движком **FastReport** (+ встроенная таблица / MS Excel /
MS Word). Поля тела/`[Данные]` сжаты VCLZip → читать/писать только через HTTP-эндпоинты `/report/*`
(.exe запущен и авторизован). **Полное руководство — [docs/10](../../docs/10-руководство-по-отчётам.md)**,
устройство канала/сжатия — [docs/08](../../docs/08-формы-dream.md).

## Рабочий процесс (инструменты tools/)
> Запускай инструменты как `python "${CLAUDE_PLUGIN_ROOT}/tools/<script>.py" …`
> (в примерах ниже `tools/` = `${CLAUDE_PLUGIN_ROOT}/tools/`; туда же пишутся `_report_*`/`_out.txt`).
```bash
python tools/buhta_client.py --report-list [--filter ТОРГ] [--type 0] [--group G]   # найти шаблон
python tools/buhta_client.py --report-get "<ключ>"        # тело -> tools\_report_<имя><ext>, данные -> .data
# править тело локально (FR4/таблица — текст; FR3/Excel/Word — заменить файл целиком)
python tools/buhta_client.py --report-set-template "<ключ>" tools\_report_<имя>.fr3   # запись тела (авто-бэкап)
python tools/buhta_client.py --report-set-data "<ключ>" tools\_report_<имя>.data       # запись [Данные]
python tools/buhta_client.py --report-show  "<ключ>" [-p "имя=значение"]   # предпросмотр в .exe
python tools/buhta_client.py --report-print "<ключ>" [-p "имя=значение"]   # печать
python tools/buhta_client.py --report-print-doc "<таблица>" --ids "1,2,3" [--vid 0]   # N экз. по документам
# откат: --report-set-template "<ключ>" tools\_report_<имя>_backup<ext>
```

## Типы шаблонов (`[ТипШаблона]`) и поле тела
| Тип | Движок | Поле тела | Тело правится |
|---|---|---|---|
| `0` | FastReport 3 | `[Шаблон]` (.frf бинарь) | только целиком (blob) |
| `1` | Встроенная таблица | `[ШаблонExcel]` (текст BUHTA_OBJECT_LIST) | текст |
| `2` | **MS Excel** | `[ШаблонMSExcel]` (.xls) | только целиком |
| `3` | MS Word | `[ШаблонMSWord]` (.doc) | только целиком |
| `4` | **FastReport 4** | `[Шаблон]` (.fr3 XML) | текст |

**Запомни: 2 = MS Excel, 4 = FastReport 4** (легко перепутать). `/report/get` сам распаковывает тело и
отдаёт `bodyKind` (text/blob) + `ext`; тело/`[Данные]` ходят base64, файлы пишутся бинарно.

## Железные правила
1. **Только через /report/*** — поля сжаты VCLZip; ручная правка в БД испортит данные.
2. **Бэкап есть** — перед каждым `set` авто-сохранение `_report_<имя>_backup<ext>` + `.data`. Откат — повторный `set` бэкап-файлом.
3. **Правки в БД запущенного .exe** (клиентская копия), эталон «Стандартная» не трогаем.
4. **Бинарное тело** (FR3/Excel/Word) — заменяется целиком (экспорт из дизайнера); текстом правится только FR4-XML и встроенная таблица.
5. Сначала `--report-get`, посмотреть тип/структуру; не выдумывать имена полей/запросов.

## Печать
- **По имени:** `--report-show`/`--report-print` → `MainPrepareReport`/`MainPrintReport`. Параметры
  `-p "имя=значение"` → `TParam` (в шаблоне `GETPARAM`); глобальные — `SetGlobalVar`/`GETGLOBALVAR`.
- **N экземпляров по документу** (напр. 100 накладных): `--report-print-doc "<таблица>" --ids "id1,id2,..."`
  → `ShowReportTableLinkPrint` (диалог привязанных к таблице отчётов, печать по списку записей master).
- Вызовы блокируют ответ, пока открыт предпросмотр/диалог (клиент ждёт до 600 c) — это штатно.

## `[Данные]` (наборы / master-detail)
Сериализованное дерево наборов: корень — master (документ), дочерние — detail (строки), связь полями
`MasterFieldName`/`LinkFieldName` (`TbmBandDataSet`). Бинарь — правится круговым переносом
(`get`→`set-data` тем же файлом) или в дизайнере БУХты. Подробно — docs/10 §4.

## Рецепт: напечатать N накладных по документам
1. `--report-list --filter ТОРГ` → выбрать «Товарная накладная ТОРГ-12» (тип 0, master-detail).
2. Определить таблицу документов и ID нужных записей.
3. `--report-print-doc "<таблица документов>" --ids "<id1,id2,...>"` → выбрать шаблон в диалоге → печать пачкой.

## Рецепт: поправить шаблон
1. `--report-get "<ключ>"` → определить тип; тело в файл.
2. FR4/таблица — править текст файла; FR3/Excel/Word — заменить файл целиком (новый экспорт из дизайнера).
3. `--report-set-template "<ключ>" <файл>` (авто-бэкап) → `--report-show` проверить → при необходимости откат.

## Завершение
- После правки: `--report-show` показывает шаблон без ошибок; round-trip без правок даёт идентичные байты.
- Кратко отчитаться: что изменено (тело/[Данные]/метаданные), как проверено, что в бэкапе.
- Пользовательские формы (диалоги/кнопки/скрипты) — отдельный skill [buhta-forms](../buhta-forms/SKILL.md).
  Расчёт зарплаты/налогов — [buhta-zarplata](../buhta-zarplata/SKILL.md).
